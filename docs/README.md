# docs/

Questa cartella contiene la documentazione storica delle prime versioni di TrekTrak.

- **`docs/superpowers/specs/`** — Design spec delle versioni 0.1.0 → 0.6.0.
- **`docs/superpowers/plans/`** — Implementation plan corrispondenti.

Il workflow attivo è in **`backlog/`** (CLI [backlog.md](https://backlog.md)):

- `backlog/tasks/` — task aperti e completati
- `backlog/docs/` — analisi critiche, bug log, persona tests, feature suggestions

Per la storia recente vedi anche **[CHANGELOG.md](../CHANGELOG.md)** alla root.
